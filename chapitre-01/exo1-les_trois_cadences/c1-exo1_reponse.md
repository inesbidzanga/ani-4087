Exercice 1 

1. Calcul de la duree totale d'une image :
   
La formule est : Duree (ms)= 1000/Frequence (Hz)

  Applications numeriques :

 * Pour 72 Hz : 1000 / 72 = 13,888 ms (13,9 ms en arrondi)
 * Pour 90 Hz : 1000 / 9 = 11,111 ms (11,1 ms en arrondi)
 * Pour 120 Hz : 1000 / 120 = 8,333 ms (8,3 ms en arrondi)
   
2. Soustraction du temps de traitement (8 ms)
   
On retire les 8 ms pour chaque frequence :

 * Pour 72 Hz : 13,9 - 8 = 5,9 ms 
 * Pour 90 Hz : 11,1 - 8 = 3,1 ms 
 * Pour 120 Hz : 8,3 - 8 = 0,3 ms 
   
3. Resultat final a rendre
 5,9, 3,1 et 0,3
